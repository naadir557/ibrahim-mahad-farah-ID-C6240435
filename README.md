Student.java

This class implements a simple Student Management System using Object-Oriented Programming. It demonstrates encapsulation, constructors, age and GPA validation, a shared university name, student information display, and a method to determine whether a student has passed. Four Student objects are created to demonstrate the required operations.

BankAccount.java

This class demonstrates encapsulation using a simple bank account system. It contains an account number, customer name, and private balance. The balance is accessed through a getter and updated using deposit and withdrawal methods. The program also validates the initial balance and transaction amounts.
